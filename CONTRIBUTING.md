# Contributing

This is a personal project. Issues and contributions are welcome; availability
and response times may vary. Use an issue to describe a bug, idea or question,
including reproduction steps and relevant versions where applicable. Please
omit credentials, personal information and private logs.

See [README.md](README.md) for development requirements and `make check`, and
[AGENTS.md](AGENTS.md) for module entry points and the local Verity workflow.
Keep changes focused and describe the checks performed. Review
[publication preparation](PUBLICATION.md) before sharing experimental records
or third-party material.
