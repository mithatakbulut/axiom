# Security boundaries

Vigil records allowlisted hook fields and hashes selected inputs for correlation. It does not ingest Codex transcripts or store raw prompts, output, project directories, or advisor recommendations. Evidence text is explicitly submitted; keep it and its references free of secrets. Pattern filtering cannot recognize every secret. SQLite, backups and install snapshots are local private files. Event and runtime snapshots expire on ingest; task contracts and evidence remain in the database for auditing.

Advisor approval and quota checks happen before a child process is started. Observe mode never runs an advisor; Assist and the default autonomous policy require explicit terminal approval. Autonomous Stop requires disabled shadow mode and approval enforcement, a qualifying detector decision and an unused budget. Reservation uses one SQLite statement across hook processes, including after crashes; an abandoned reservation still counts and stops occupying a parallel slot when its lease expires.

The child uses Codex's read-only command sandbox, no approval escalation, an ephemeral session, disabled hooks, plugins, multi-agent features and hosted web search, and a minimal environment. Codex uses its existing sign-in; the child may still access authentication or write internal state as part of its own operation. A read-only command sandbox is not a confidentiality boundary for repository contents. The advisor receives a bounded JSON packet of derived signals and, when defined, the task title and a few unmet criteria. It can read project files, so only authorize it on repositories whose content may be processed by your Codex account. The recommendation is untrusted advisory text and does not change existing approvals.

A timeout may terminate only the process group Vigil created for that advisor. Resource monitoring only reads process and disk information and cannot terminate arbitrary processes. The process list does not establish ownership after reparenting. Primary model and subagent use is observed where hooks are available; Vigil enforces only operations it owns.

Hook registration is explicitly subject to Codex's trust review. No trust bypass is used. Hook errors fail open; other matching hooks can take precedence. CLI and MCP are local interfaces, not a boundary against other software running as the same OS user.
